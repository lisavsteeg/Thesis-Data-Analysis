# Thesis Data Analysis

The relevant R scripts for my MSc thesis on the association between livestock activity and wild mammal communities

## Main analysis scripts

These eight scripts were used for the final data analysis.

### Data preparation
1. `full cleaned dataset.R` — Data cleaning and preparation
2. `Camera trap operations matrix.R` — Information on camera functioning and erroneous deployments
3. `year corrections.R` — Corrections for observations when only the year in the observation date was incorrect

### Main analyses
4. `Livestock activity.R` — Livestock activity metrics and livestock activity groups
5. `iNext.R` — Species richness and diversity analysis
6. `NMDS script.R` — Community composition analysis
7. `diet.R` — Analysis by diet group
8. `Body size.R` — Analysis by mammal body-size class

## Other scripts

The remaining scripts contain practice, exploratory analyses and supporting work.
